# Kurulu skill'ler

Bu klasördeki skill'ler [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill)
deposundan alındı (MIT, lisans metni `TASTE-SKILL-LICENSE` dosyasında).

Yalnızca `skills/` klasörü kopyalandı; deponun README görselleri ve yazarın
kendi görsel işleme betikleri alınmadı — bu projede işleri yok.

| Klasör | Skill adı | Ne için |
| --- | --- | --- |
| `taste-skill` | `design-taste-frontend` | Açılış sayfası / portfolyo / yeniden tasarım; "şablon gibi görünmeyen" arayüz |
| `taste-skill-v1` | `design-taste-frontend-v1` | Aynısının eski sürümü |
| `redesign-skill` | `redesign-existing-projects` | Var olan bir arayüzü önce denetleyip sonra yenilemek |
| `brandkit` | `brandkit` | Marka kimliği: renk, tipografi, ses tonu |
| `minimalist-skill` | `minimalist-ui` | Minimal yön |
| `brutalist-skill` | `industrial-brutalist-ui` | Brutalist / endüstriyel yön |
| `soft-skill` | `high-end-visual-design` | Yumuşak, üst segment görsel dil |
| `stitch-skill` | `stitch-design-taste` | Bileşenleri tutarlı bir dilde birleştirmek |
| `image-to-code-skill` | `image-to-code` | Ekran görüntüsünden arayüz kodu |
| `imagegen-frontend-web` | `imagegen-frontend-web` | Web arayüzü için görsel üretimi |
| `imagegen-frontend-mobile` | `imagegen-frontend-mobile` | Mobil arayüz için görsel üretimi |
| `gpt-tasteskill` | `gpt-taste` | Kısa tasarım sağduyusu kuralları |
| `output-skill` | `full-output-enforcement` | Kod üretiminde kısaltma/`// ...` kalıplarını yasaklar |

Not: bu skill'ler açılış sayfası ve portfolyo işleri için yazılmış. Decha'nın
mevcut "bürokratik dosya/terminal" tasarım dili zaten kurulu; skill'lerin
varsayılan estetiğini körü körüne uygulamak siteyi bozar. Yön değiştirmek
istemiyorsanız bunları yalnızca denetim/fikir için kullanın.
